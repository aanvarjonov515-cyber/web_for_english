# English Vocabulary Trainer

Personal English vocabulary learning web application.

The project is designed to help a learner improve:

- Reading
- Pronunciation
- Writing
- Listening
- Vocabulary retention
- Learning consistency

---

## 1. Project Goal

The user enters English vocabulary in a simple format.

Example:

```text
coffee n /'kofi/
Daddy n /'dædi/
day n /dei/
English n /'inglıf/
fine adj /famn/
first name n /fsist ,neim/
Good afternoon! excl /gud a:fto'nu:n/
